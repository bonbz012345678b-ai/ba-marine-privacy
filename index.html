1. Purpose

BA Marine Signal BASIC and PRO are Android applications for marine serial communication monitoring, testing and diagnostics.

2. Data processed

The applications process data received from compatible USB serial equipment. Depending on the connected equipment, this may include NMEA sentences, vessel positions, equipment identifiers and other technical information.

3. Device permissions

The reviewed application releases use Android USB Host functionality to access compatible USB serial devices with user authorization. Their compiled manifests do not declare Internet or Android location permissions.

4. Recording and storage

BA Marine Signal PRO includes receive recording and replay features. In the reviewed release, recorded data and timestamps are held in application memory during use. No file-based recording mechanism was identified in the reviewed application source.

5. Third-party components

The applications include USB serial communication libraries and Apache HttpCore. The reviewed releases did not show known advertising or analytics SDKs among the class names examined. This statement describes the technical review and does not guarantee the absence of all third-party data processing.

6. Intended users

The applications are intended for technical diagnostics and are not specifically designed for children. They are not certified navigation or safety equipment.

7. Data retention

In the reviewed versions, RX recordings and their timestamps are held in application memory for recording and replay. Starting a new recording clears the previous recording. The reviewed application code does not implement persistent file storage for these recordings. Memory is released according to the Android application process lifecycle. Connected external equipment may have its own data storage practices.
